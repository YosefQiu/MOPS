# MOPS VTP Analysis Tools

A collection of command-line tools for analyzing and manipulating VTK PolyData (VTP) trajectory files generated by MOPS (Modular Ocean Particle Simulator).

## Tools Overview

| Tool | Purpose | Input |
|------|---------|-------|
| `vtp_batch_checker.py` | Batch analyze temperature/salinity ranges | Directory of VTP files |
| `vtp_attribute_inspector.py` | Detailed attribute analysis with histograms | Single VTP file |
| `particle_stuck_detector.py` | Detect stuck/stationary particles | Merged trajectory VTP |
| `vtp_merger.py` | Merge multiple VTP files into one | Directory of VTP files |

---

## 1. vtp_batch_checker.py

**Purpose**: Quickly scan a directory of VTP files and extract temperature and salinity ranges across all files.

### Usage

```bash
# Check current directory
python vtp_batch_checker.py .

# Check specific directory
python vtp_batch_checker.py /path/to/vtp/files

# Save report to file
python vtp_batch_checker.py /path/to/vtp/files --output report.txt

# Show help
python vtp_batch_checker.py -h
```

### Output

- Per-file statistics table (points, temperature range, salinity range)
- Overall min/max/range across all files
- Data quality warnings (negative values, missing data)

### Example Output

```

...

Overall Ranges Across All Files:
  Temperature: 5.234567 - 28.567890 (range: 23.333323)
  Salinity: 30.123456 - 35.987654 (range: 5.864198)
```

## 2. vtp_attribute_inspector.py

**Purpose**: Perform detailed analysis of attributes in a single VTP file, including statistics, histograms, and special value detection.

### Usage

```bash
# Inspect a VTP file (uses VTK library)
python vtp_attribute_inspector.py trajectory.vtp

# Force XML parsing mode
python vtp_attribute_inspector.py trajectory.vtp --xml-only

# Show help
python vtp_attribute_inspector.py -h
```

### Requirements

- **Recommended**: `vtk` library for full analysis
- **Fallback**: XML parsing (limited to metadata)

```bash
pip install vtk
```

### Output

- File statistics (points, lines, arrays)
- List of all available point data arrays
- Detailed statistics per attribute (min, max, mean, std)
- Special value detection (NaN, Inf, zeros, negatives)
- Value distribution histogram (10 bins)

## 3. particle_stuck_detector.py

**Purpose**: Detect particles that remain stationary for extended periods in merged trajectory files.

### Usage

```bash
# Analyze trajectory with 100 particles
python particle_stuck_detector.py trajectory.vtp 100

# Custom thresholds
python particle_stuck_detector.py trajectory.vtp 100 \
    --threshold 1e-5 \
    --consecutive 10

# Save results to custom CSV file
python particle_stuck_detector.py trajectory.vtp 100 -o results.csv

# Show help
python particle_stuck_detector.py -h
```

### Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| `vtp_file` | Path to merged trajectory VTP file | Required |
| `num_particles` | Number of actual particles (not line segments) | Required |
| `-t, --threshold` | Distance threshold (meters) for stuck detection | 1e-6 |
| `-c, --consecutive` | Minimum consecutive stationary steps | 5 |
| `-o, --output` | Output CSV file path | `<input>_stuck_merged.csv` |

### Requirements

```bash
pip install pyvista numpy
```

### Output

- Console report with stuck particle details
- CSV file with summary statistics

## 4. vtp_merger.py

**Purpose**: Merge multiple VTP trajectory files into a single file while preserving all point data attributes.

### Usage

```bash
# Merge all PathLine_*.vtp files in directory
python vtp_merger.py ./input_folder output_merged.vtp

# Use custom file pattern
python vtp_merger.py ./input_folder output.vtp --pattern "trajectory_*.vtp"

# Show help
python vtp_merger.py -h
```

### Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| `input_folder` | Directory containing VTP files | Required |
| `output_file` | Output merged VTP filename | Required |
| `-p, --pattern` | Glob pattern for file matching | `PathLine_*.vtp` |

### Requirements

```bash
pip install vtk
```

### Features

- Merges all point data attributes (temperature, salinity, velocity, etc.)
- Preserves line connectivity within each file
- Automatically sorts files by starting step number
- Sets default coloring attribute for ParaView

### Example Output

  ...

======================================================================

  Found attribute: temperature (1 components)

## Common Workflows

### Workflow 1: Merge and Analyze Trajectories

```bash
# Step 1: Merge trajectory files
python vtp_merger.py ./trajectories merged_output.vtp

# Step 2: Inspect merged file attributes
python vtp_attribute_inspector.py merged_output.vtp

# Step 3: Check for stuck particles
python particle_stuck_detector.py merged_output.vtp 100
```

### Workflow 2: Batch Quality Check

```bash
# Quick scan of all files in directory
python vtp_batch_checker.py ./simulation_output --output quality_report.txt

# Detailed inspection of suspicious files
python vtp_attribute_inspector.py ./simulation_output/suspicious_file.vtp
```

### Workflow 3: Data Validation Pipeline

```bash
# 1. Check overall ranges
python vtp_batch_checker.py ./data

# 2. Merge files
python vtp_merger.py ./data merged.vtp

# 3. Detect issues
python particle_stuck_detector.py merged.vtp 100 -o stuck_analysis.csv

# 4. Inspect problematic regions
python vtp_attribute_inspector.py merged.vtp
```

## File Naming Convention

All tools follow consistent naming:

- **Snake case**: `tool_name.py`
- **Descriptive**: Name indicates purpose
- **Verb prefix**: Action-oriented (`check`, `merge`, `detect`)

## Troubleshooting

### VTK Not Installed

If you see "VTK not available" warnings:

```bash
pip install vtk
```

### PyVista Not Found

For `particle_stuck_detector.py`:

```bash
pip install pyvista
```

### Permission Denied

Make scripts executable:

```bash
chmod +x *.py
```

### No Files Found

Check your glob pattern and directory path:

```bash
# List files to verify pattern
ls ./your_directory/PathLine_*.vtp

# Use absolute paths if relative paths fail
python vtp_merger.py /absolute/path/to/files output.vtp
```
